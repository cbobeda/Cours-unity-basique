## PROJECTS

il y a plusieurs elements present, tout dabord l'onglet Projects qui permet de manager ses projet unity. Dans cet onglet on peut voir plusieurs bouttons.
Le bouton "+ New project" qui nous permet de créé de nouveau projet, ensuite nous avons "Add" qui permet d'ajouté des projet deja existant qui n'on pas été detecter par unity hub
<img width="1271" height="717" alt="image" src="https://github.com/user-attachments/assets/ced1b95f-1a47-4db4-beed-2f9332004102" />

## INSTALLS

Cet ongles sers a géré les differentes version du moteur unity installé, on peut en installé de nouvelles via le bouton "Install Editor" ou en ajouté via le bouton "Locate" enfin on peut modifer une installation en utilisant le bouton "Manage" pour chaque version installée

## AUTRE

Les trois derniers onglets sont moins interessant, learn possède different projet deja plus ou moins avancé avec un tutoriel permettant de rajouter des fonctions.
